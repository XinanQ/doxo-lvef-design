# data

- `raw/`: files exactly as we downloaded them from the papers. Please don't
  edit these.
- `extracted/`: stuff we make from them, like numbers digitized from a figure.
  Keep group means separate from individual-animal data and from the papers'
  own model predictions.

Both folders are empty for now. For each source we add, try to write down: which
study and group, the animal or cohort ID (if there is one), when the doses were
given and in what units, the visit times and what t = 0 means (in our pilot it's
the first dose), LVEF, whether the error bars are SD or SEM, how many animals
were measured at each visit, and where in the paper it came from. For digitized
values, also note the figure panel and how much two extractions differed.

Let's check what we're allowed to share before putting any file from a paper in
here.
